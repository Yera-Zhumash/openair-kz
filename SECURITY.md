# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue. Report privately via GitHub
"Report a vulnerability" (Security tab) or email **REPLACE_CONTACT_EMAIL**.
We aim to reply within 7 days.

## Supported versions

Only the latest release on `main` receives security fixes.

## Security and privacy practices

- The public map and API require no account; no personal data is collected from
  sensors or visitors.
- Optional contributor accounts store only a username and email address.
- Passwords are stored as salted hashes (never in plain text).
- All production connections use HTTPS.
- Sensor locations at private homes are stored with reduced precision (about 1 km).
- Personal data can be deleted on request (email the contact above).
- Handling of personal data follows the Law of the Republic of Kazakhstan
  "On Personal Data and Its Protection".
